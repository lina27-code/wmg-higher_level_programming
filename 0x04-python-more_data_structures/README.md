# 0x04 - Python More Data Structures: Set, Dictionary

This project introduces sets, dictionaries, and lambda functions in Python.

## Learning Objectives
- Sets and their methods
- Dictionaries and their methods
- Lambda functions
- map, filter, reduce functions
- When to use sets vs lists vs dictionaries

## Files
- `0-square_matrix_simple.py` - Square matrix values
- `1-search_replace.py` - Replace elements in list
- `2-uniq_add.py` - Add unique integers
- `3-common_elements.py` - Find common elements in sets
- `4-only_diff_elements.py` - Find elements in only one set
- `5-number_keys.py` - Count keys in dictionary
- `6-print_sorted_dictionary.py` - Print dictionary sorted by keys
- `7-update_dictionary.py` - Update dictionary
- `8-simple_delete.py` - Delete key from dictionary
- `9-multiply_by_2.py` - Multiply dictionary values by 2
- `10-best_score.py` - Find key with best score
- `11-multiply_list_map.py` - Multiply list using map
- `12-roman_to_int.py` - Convert Roman numeral to integer
- `100-weight_average.py` - Calculate weighted average
- `101-square_matrix_map.py` - Square matrix using map
- `102-complex_delete.py` - Delete keys with specific value
- `103-python.c` - Python list and bytes info (C)
