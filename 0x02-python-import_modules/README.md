# 0x02 - Python import & modules

This project introduces modules, imports, and command-line arguments in Python.

## Learning Objectives
- Import functions from another file
- Create modules
- Use `dir()` function
- Prevent code execution when imported
- Use command-line arguments with `sys.argv`

## Files
- `0-add.py` - Import and use add function
- `1-calculation.py` - Import and use multiple functions
- `2-args.py` - Print number and list of arguments
- `3-infinite_add.py` - Add all arguments
- `4-hidden_discovery.py` - Discover hidden module names
- `5-variable_load.py` - Import variable from module
- `100-my_calculator.py` - Calculator with command-line arguments
- `101-easy_print.py` - Print without print()
- `102-magic_calculation.py` - Magic calculation function
- `103-fast_alphabet.py` - Print alphabet without loops or conditionals
