## Description
This project introduces fundamental concepts of Python programming:
- Printing text and numbers
- Formatting strings (f-strings)
- String manipulation and slicing
- Running Python code via Shell scripts
- Understanding Python bytecode and sys modules

## Requirements
- Editors: `vi`, `vim`, `emacs`
- OS: Ubuntu 20.04 LTS
- Python Version: 3.8.5
- Code Style: `pycodestyle` (version 2.8.*)
