# 0x03 - Python Data Structures: Lists, Tuples

This project introduces lists and tuples in Python.

## Learning Objectives
- Lists and how to use them
- Differences between strings and lists
- List methods and operations
- List comprehensions
- Tuples and their usage
- Tuple packing and unpacking
- del statement

## Files
- `0-print_list_integer.py` - Print all integers in a list
- `1-element_at.py` - Get element at index
- `2-replace_in_list.py` - Replace element at index
- `3-print_reversed_list_integer.py` - Print list in reverse
- `4-new_in_list.py` - Replace element without modifying original
- `5-no_c.py` - Remove characters c and C
- `6-print_matrix_integer.py` - Print matrix of integers
- `7-add_tuple.py` - Add two tuples
- `8-multiple_returns.py` - Return length and first character
- `9-max_integer.py` - Find max integer in list
- `10-divisible_by_2.py` - Find multiples of 2
- `11-delete_at.py` - Delete element at index
- `12-switch.py` - Switch variables
- `13-is_palindrome.c` - Check if linked list is palindrome (C)
- `100-print_python_list_info.c` - Print Python list info (C)
